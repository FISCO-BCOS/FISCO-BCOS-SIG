## 测试过程中发现并修复的 Bug（累计8个）

| # | Bug | 根因 | 修复 | 发现方式 |
|---|-----|------|------|----------|
| 1 | Swagger + Java 21 不兼容 | springfox 2.9.2 不支持 Servlet 5.0 | 移除 Swagger 依赖 | 后端启动 |
| 2 | ESLint 配置缺失 | 无 .eslintrc.js | 添加配置 + lintOnSave:false | 前端编译 |
| 3 | MySQL 地址错误 | 139→170 | 更新 application.yml | API 测试 |
| 4 | Header.vue 检查错误Cookie | `address` → `token` | 修改 Cookie 检查逻辑 | 前端登录 |
| 5 | Vue 组件 id="app" 冲突 | 5个组件都用 id="app" | 改为唯一 id | 页面渲染 |
| 6 | **路由路径不匹配** | /evidenceCreate vs /evidence/create | 统一为斜杠分隔 | 页面空白 |
| 7 | **Navigator.vue 路由路径旧** | /evidenceCreate → /evidence/create | 修改 handleSelect | 导航跳转 |
| 8 | 登出未清除所有 Cookie | 只清除了 address | 清除全部5个 Cookie | 登出测试 |

## 测试结论

### 总体评价：✅ **优秀** (86.7% 通过率, 0 失败)

**核心成就：**
- ✅ **注册→登录→首页** 完整用户流程通过浏览器操作验证
- ✅ **首页仪表盘** 4个统计卡片 + 表格 + 快捷按钮全部渲染正确

- ✅ **表单校验** 空输入校验 + 错误提示正确
